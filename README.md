# Portfolio Website - Iqbal Fauzan

Welcome to the repository of my personal portfolio website.

I am an **IoT & Automation Engineer** specializing in Industrial IoT, Automation Systems, Machine-to-Machine (M2M) Communication, Industrial Networking, and Factory Digitalization. This website serves as my professional portfolio, showcasing my experience, technical skills, certifications, and engineering projects.

> **Live Demo:** https://your-username.github.io/portfolio-web/

---

# 🌟 Features

* **Professional Engineering Portfolio**
  Clean, modern, and blueprint-inspired interface designed specifically for engineering professionals.

* **Interactive Resume (CV)**
  Displays education, experience, technical skills, certifications, and achievements.

* **Project Portfolio**
  Showcases industrial automation and IoT projects with project descriptions, technology stack, architecture, and implementation gallery.

* **Multi-Language Support (i18n)**
  Supports English 🇺🇸, Indonesian 🇮🇩, and German 🇩🇪 without page reload.

* **Print / Export to PDF**
  Optimized print layout for generating ATS-friendly PDF resumes.

* **Responsive Design**
  Fully responsive across desktop, tablet, and mobile devices.

* **Smooth Animations**
  Built with CSS animations and the Intersection Observer API for a modern user experience.
