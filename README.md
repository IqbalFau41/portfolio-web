## 🌟 Features

*   **Clean & Professional UI:** Designed with a modern, blueprint-inspired theme tailored for engineering professionals.
*   **Multi-Language Support (i18n):** Seamlessly switch between English (EN), Indonesian (ID), and German (DE) without reloading the page.
*   **Print-Ready / Export to PDF:** The layout is highly optimized for printing. Clicking the "Download PDF" button will strip away UI elements (like the navbar) to generate a clean, ATS-friendly PDF resume.
*   **Responsive Design:** Fully responsive and readable across desktops, tablets, and mobile devices.
*   **Smooth Animations:** Implements subtle scroll-reveal effects and pulsing live-status indicators using Intersection Observer API and CSS.

## 🛠️ Tech Stack

*   **HTML5** for semantic structure.
*   **Tailwind CSS (via CDN)** for rapid and responsive styling.
*   **Vanilla CSS3 (`style.css`)** for custom UI components (blueprint grids, timeline circuits) and print media queries.
*   **Vanilla JavaScript (`script.js`)** for handling the multi-language dictionary and scroll animations.
